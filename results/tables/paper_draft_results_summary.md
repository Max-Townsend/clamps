# paper_draft_results manuscript companion stats

This summary lists the descriptive and inferential results from the chapter-level analyses.

## Figure 2
- A 10 (assigned clamp group) x 2 (input device) between-subject ANOVA on participant-averaged late adaptation showed a main effect of group (F(9, 464) = 16.66, p < .001, eta_p^2 = 0.244 [0.187, 0.361]), a main effect of input device (F(1, 464) = 12.44, p < .001, eta_p^2 = 0.026 [0.006, 0.059]), and a group x device interaction (F(9, 464) = 2.07, p = .031, eta_p^2 = 0.039 [0.027, 0.092]).
- Holm-corrected one-sample t-tests on participant means averaged across the four assigned clamp magnitudes were significant in groups 1, 2, 3, 4, 5, 6, 7, 8 (all p_Holms <= .003), but not in groups 9, 10 (all p_Holms >= .811).
- In the 40-clamp follow-up, pooled Holm-corrected one-sample t-tests against zero were significant at 29 of 40 clamp magnitudes (all p_Holms <= .035), but not at any clamp in the 135-170 deg range (all p_Holms = 1.000). Split by device, Mouse showed significant late adaptation at 27 of 40 clamp magnitudes (all p_Holms <= .035) and Trackpad at 15 of 40 (all p_Holms <= .036); no 135-170 deg clamp was significant for Mouse (all p_Holms = 1.000) or Trackpad (all p_Holms = 1.000).
- A 10 (assigned clamp group) x 2 (input device) between-subject ANOVA on participant-averaged early STL showed a main effect of group (F(9, 464) = 2.31, p = .015, eta_p^2 = 0.043 [0.031, 0.105]), but no main effect of input device (F(1, 464) = 0.30, p = .586, eta_p^2 = 0.001 [0.000, 0.012]) and no group x device interaction (F(9, 464) = 0.61, p = .790, eta_p^2 = 0.012 [0.010, 0.070]). Holm-corrected one-sample t-tests against zero were significant only at the 80 deg clamp (p_Holm = .015), whereas none of the 135-170 deg clamps survived correction (all p_Holms = 1.000).
- A corresponding 10 (assigned clamp group) x 2 (input device) between-subject ANOVA on participant-averaged washout STL showed a main effect of group (F(9, 464) = 3.27, p < .001, eta_p^2 = 0.060 [0.038, 0.132]), a main effect of input device (F(1, 464) = 5.97, p = .015, eta_p^2 = 0.013 [0.001, 0.036]), but no group x device interaction (F(9, 464) = 1.59, p = .115, eta_p^2 = 0.030 [0.017, 0.090]), but no individual washout clamp survived Holm correction (all p_Holms >= .067).

## Figure 3
- A 2 (phase) x 10 (assigned clamp group) x 2 (input device) mixed ANOVA on participant-averaged mean hand angle showed a main effect of phase (F(1, 464) = 288.53, p < .001, eta_p^2 = 0.383 [0.298, 0.513]), a phase x group interaction (F(9, 464) = 11.31, p < .001, eta_p^2 = 0.180 [0.130, 0.306]), a phase x device interaction (F(1, 464) = 12.75, p < .001, eta_p^2 = 0.027 [0.008, 0.065]), but no phase x group x device interaction (F(9, 464) = 1.69, p = .088, eta_p^2 = 0.032 [0.020, 0.085]). Holm-corrected paired t-tests were significant at 26/40 clamps (all p_Holms <= .049) and at 0/8 of the 135-170 deg clamps (all p_Holms = 1.000).
- In the peak range, late adaptation exceeded baseline by 27.49 deg (t(98) = 12.45, p < .001, cohens_dz = 1.25 [0.87, 1.77]). In the 135-170 deg range, the phase difference was negligible (t(96) = 0.27, p = .789, cohens_dz = 0.03 [-0.17, 0.24]).
- A corresponding mixed ANOVA on between-participant spread of mean hand angle, quantified as absolute deviation from the phase-specific group median, showed a main effect of phase (F(1, 464) = 167.74, p < .001, eta_p^2 = 0.266 [0.198, 0.385]), but no phase x group interaction (F(9, 464) = 1.74, p = .077, eta_p^2 = 0.033 [0.025, 0.101]), no phase x device interaction (F(1, 464) = 1.99, p = .158, eta_p^2 = 0.004 [0.000, 0.022]), and no phase x group x device interaction (F(9, 464) = 1.11, p = .354, eta_p^2 = 0.021 [0.013, 0.069]). Holm-corrected paired t-tests on spread were significant at 25/40 clamps (all p_Holms <= .025) and at 7/8 of the 135-170 deg clamps (significant tests: all p_Holms <= .011; remaining test: p_Holm = .542).
- In the 135-170 deg clamps, bias direction predicted late adaptation (Wald chi2(2, N = 96 participants) = 33.18, p < .001, eta_p^2 = 0.165 [0.073, 0.290]). Relative to the near-zero group, Incorrect was -6.38 deg lower [-10.07, -2.70] (p_Holm < .001) and Correct was 7.62 deg higher [3.99, 11.26] (p_Holm < .001).

## Figure 4
- For late adaptation averaged across each participant's assigned clamps, Mouse participants were higher than Trackpad (Mouse 18.25 [15.67, 20.83], Trackpad 13.16 [10.56, 15.76], Welch t(467.87) = 2.74, p = .006, g = 0.25 [0.06, 0.43]). A clamp-adjusted model gave Mouse - Trackpad = 5.93 deg [2.79, 9.07], p < .001.
- The cleaner simple effect for the 'medium-size clamps' sentence is the peak-range contrast: Mouse 35.41 [29.81, 41.00] versus Trackpad 21.55 [15.87, 27.22], Welch t(96.94) = 3.50, p < .001, g = 0.70 [0.32, 1.15]; clamp-adjusted Mouse - Trackpad = 13.94 deg [5.91, 21.98], p < .001.
- Task-aligned baseline bias showed no device difference (Mouse -0.08 [-1.05, 0.88], Trackpad -0.09 [-1.10, 0.91], Welch t(457.03) = 0.01, p = .988, g = 0.00 [-0.18, 0.19]).
- Raw signed baseline bias is the same device comparison without clamp-sign task alignment (Mouse -4.28 [-5.11, -3.46], Trackpad 1.23 [0.23, 2.22], Welch t(423.50) = -8.43, p < .001, g = -0.78 [-0.98, -0.59]).
- Spatial bias pattern tests are separated by bias frame: Task-aligned (Wald chi2(3, N = 480 participants) = 2.10, p = .553, eta_p^2 = 0.001 [0.000, 0.007]) and raw signed (Wald chi2(3, N = 480 participants) = 117.92, p < .001, eta_p^2 = 0.054 [0.036, 0.077]).
- For reach variability, the rank-based and log-scale device contrasts match the plotted medians better than mean-based Welch tests because the SD distributions are strongly right-skewed. Early variability was higher for Mouse (participant-average median 14.31 [13.37, 15.89] versus 9.82 [9.17, 11.53], Mann-Whitney U = 35683, p < .001, rank-biserial = 0.253 [0.148, 0.355]; clamp-adjusted log-SD ratio = 1.33 [1.16, 1.52], p < .001). Late variability showed the same direction (participant-average median 12.21 [11.24, 14.22] versus 9.09 [8.17, 9.98], Mann-Whitney U = 35478, p < .001, rank-biserial = 0.246 [0.138, 0.348]; clamp-adjusted log-SD ratio = 1.37 [1.20, 1.55], p < .001). The raw-value late-variability term table still shows a pointer effect (Wald chi2(1, N = 484 participants) = 9.57, p = .002, eta_p^2 = 0.015 [0.002, 0.038]).
